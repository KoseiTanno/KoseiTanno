# ガブリ・バーガー — リソグラフ版のスクロリテリング

架空のハンバーガー屋のランディングページ。同じスクロール連動の骨組みを、
まったく別の造形言語で組み直したものです（静かな和の版は `../sumitsugi/`）。

公開版: https://claude.ai/code/artifact/0766fcdd-7c62-44d1-abe1-491c3938adc7

## 造形の方針：リソグラフの「版」として描く

- **インクは4色だけ**（赤 `#F04E37` / 黄 `#FFC400` / 緑 `#00A05A` / 墨 `#1C1A17`）。
  具材ごとに一版目はベタ、二版目からは `multiply` で掛け合わせて色に深さを出す。
- **版ずれ**を色ごとに固定量で持つ（`REG`）。赤は右上、黄は左下、緑は右下へ 1px 強ずらす。
- **粒子**を一度だけ焼いて `destination-out` で抜く。これが無いと「印刷物」に見えない。
- **墨の輪郭**を一枚ごとに引く。これを入れた瞬間に絵が締まった。
  黄色い紙の上で黄色いチーズが消えていた問題も、輪郭で同時に解決している。
- 紙の色は**セクションごとに刷り替える**（黄 → 紙 → 赤 → 紙 → 緑 → 墨）。

書体は **Dela Gothic One**（極太の看板ゴシック）と Zen Kaku Gothic New。
`font-feature-settings:"palt"` で約物を詰めている。

## 仕掛け

| # | 画面 | 中身 |
| --- | --- | --- |
| 1 | 表紙 | バーガーを**押すと齧れる**（`destination-out` で欠けを抜き、スカッシュで潰す） |
| 2 | 組み立て | スクロールで**七段が順に落ちてくる**。着地は `easeOutBack` で跳ねる |
| 3 | 焼き | パティが焼ける。赤に墨を重ねていき、焦げと湯気が出る。温度と秒数が連動 |
| 4 | お品書き | 太罫のカード |
| 5 | 自分で積む | 具材を押すと**積み上がり、金額が変わる**。積みすぎると怒られる |
| 6 | 店 | 営業情報 |

## 実装で効いたところ

- **`renderBurger()` 一本で三画面をまかなう。** 表紙・組み立て・自分で積む、
  どれも「具材の配列」を渡すだけ。積み方・重なり・落下アニメは全部この中にある。
- **段が増えたら上バンズの取り分を減らす**（`domeK`）。でないと帽子だけ巨大になる。
- **幅は段数に連動させる。** 高さだけ縮めると、背が高いほど平べったくなる。
- スクロール量は `--p`（0→1）に正規化。固定面の高さは `window.innerHeight` ではなく
  sticky 要素の実測を使う（`100svh` を `100vh` で割ると、モバイルで最後まで進まない）。
- `prefers-reduced-motion` では固定を解き、絵は完成形で静止させる。
