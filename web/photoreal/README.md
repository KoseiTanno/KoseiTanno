## それぞれの解き方

**万年筆** — 暗室のローキー撮影に固定。漆は「柔らかい主帯＋芯のある細帯」の二層で鈍い艶を作り、
金属は階調の段差を漆より急にして、先端から扇状のヘアラインに直交する弧状の異方性ハイライトを
重ねた。ペンポイントだけ鏡面。紙は漉きむら＋繊維ストローク約1,400本、にじみは
ハロー→羽毛縁→本体→縁のピグメント溜まり→濡れ照りの5層。

**バーガー** — 暗いスタジオに温かいキーライト一灯。具材ごとにオフスクリーンへ一度だけ描く
スプライト方式で、fbm ノイズによる焼きむら・濡れた斑・縁の透けを作る。静的な層をキャッシュ化して
23ms → 16.6ms/フレームに改善。

**ホテル** — 部屋そのものをレイキャストし、太陽光は「その点から太陽方向への光路が窓開口を
通るか」で判定している。床の光の帯・桟の影・壁を昇る光・家具の影・カーテンの透過光が
**すべて同じひとつの太陽から自動的に導かれる**ので、光源の向きの矛盾が構造的に起きない。

## 検証（Opus 側で独立に実施）

3本とも、desktop / dark / mobile(390px) / reduced-motion の4条件で
**横スクロール 0・JSエラー 0・`lang=ja`**。加えて実装側が数値で確認した主な条件：

- 万年筆：引き出し線と対象の座標差 3本とも **0.00px** / 一筆の線の途切れ **0**、太さ 7–8px 一定
- バーガー：ぜんぶのせ **¥2,480** / 七層の隣接色距離 96〜246（全境界で判別可） / 60fps
- ホテル：一日141点で**時計の逆行 0件・見出しが未来を指す点 0件** /
  文字コントラスト最低 **8.05** / 3泊 **¥102,000** / 満室は再読み込みで不変
