# 実装仕様書：ガブリ・バーガー

架空のハンバーガー屋のランディングページを一枚の HTML で作る。
この文書は Opus 5 が書いた仕様であり、実装者はこの通りに作ること。
「いい感じに」の判断を実装者に預けている箇所は無い。判断が要る箇所は明記してある。

---

## 0. 成果物の形式

- **1ファイル。ビルドもライブラリも使わない。** 素の HTML / CSS / JS。
- Artifact に載せるため、`<!doctype>` `<html>` `<head>` `<body>` は**書かない**。
  ファイルは次の順で始める：`<title>` → `<link rel="preconnect">`×2 → Google Fonts の `<link>` → `<style>` → マークアップ → `<script>`。
- 外部アセット禁止。画像も CDN も使わない。**Google Fonts だけは許可**（唯一許可されたホスト）。
- 絵はすべて **Canvas 2D** で描く。SVG の線画は使わない。
- JS の先頭で `document.documentElement.lang = 'ja'` を立てる。

---

## 1. 何を作るか

三軒茶屋にある架空のハンバーガー屋 **「ガブリ」**。
造形言語は **リソグラフ印刷のポスター**。写真は一枚も使わず、刷り物として作る。

**楽しさの置きどころは「触れること」に置く。** 見て終わりの演出ではなく、
押すと反応するもの・スクロールで組み上がるもの・自分で操作できるものを中心に据える。

## 2. 色：スポットインク4色

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--red` | `#F04E37` | トマト、ソース、ベーコン、値札 |
| `--yellow` | `#FFC400` | バンズ、チーズ、卵 |
| `--green` | `#00A05A` | レタス、ピクルス、アボカド |
| `--ink` | `#1C1A17` | 線・文字・パティ |
| `--paper` | `#EFEEE9`（明）/ `#16151A`（暗） | 紙 |
| `--on-dark` | `#F7F4EC` | 濃い地の上の文字 |

- **紙の色はセクションごとに刷り替える。** `data-bg="yellow|paper|red|green|dark"` を section に置き、
  各値に対して `--bg` と `--fg` を定義する。`section{background:var(--bg);color:var(--fg)}`。
- スポットインクは明暗テーマで**変えない**。変わるのは `paper` のセクションだけ。
  赤地の文字は常に `--on-dark`、黄・緑地の文字は常に `--ink`。
- 色の定義を `@media` や `[data-theme]` の**中だけ**に書かないこと（未指定テーマで色が落ちる）。

## 4. Canvas のバーガー描画エンジン（この仕様の中核）

### 4.1 要件

**関数を一本だけ作り、三つの画面すべてをそれでまかなうこと。**
シグネチャは `renderBurger(canvas, stack, opts)`。`stack` は `[{spec, t}]` の配列で、
`t` は 0→1 の出現進捗（省略時 1）。表紙・組み立て・自分で積む、どれも配列を渡すだけで描けること。

### 4.2 具材テーブル

`h` は高さ比、`w` は幅比、`paint` は刷る版の順。

| key | 名前 | h | w | かたち | 版（色, 濃度） | 追加料金 |
| --- | --- | --- | --- | --- | --- | --- |
| `bunBottom` | バンズ（下） | .13 | .94 | 下がゆるく丸いカプセル | yellow 1.0 → red .22 | — |
| `sauce` | 特製ソース | .05 | .86 | 薄いカプセル | red 1.0 | — |
| `patty` | パティ 150g | .13 | 1.00 | 縁の粗いカプセル | ink .74 → red .40 | +400 |
| `cheese` | チーズ | .07 | .92 | カプセル＋**両端から垂れる** | yellow 1.0 | +150 |

| `bacon` | ベーコン | .05 | .90 | 波打つ帯 | red .95 → ink .38 | +250 |
| `egg` | 目玉焼き | .08 | .86 | 上が大きく波打つカプセル＋黄身の円 | yellow 1.0（黄身は red .78） | +180 |
| `tomato` | トマト | .07 | .88 | カプセル | red .92 | +120 |
| `avocado` | アボカド | .07 | .84 | カプセル | green .85 → yellow .40 | +200 |
| `pickle` | ピクルス | .04 | .80 | 薄いカプセル＋種の点 | green 1.0 | +100 |
| `lettuce` | レタス | .09 | 1.00 | 上下ともギザギザのフリル | green 1.0 | +100 |
| `bunTop` | バンズ（上） | .25 | .94 | ドーム＋白ごま | yellow 1.0 → red .22 | — |

基本の並び（下から）：`bunBottom, sauce, patty, cheese, tomato, lettuce, bunTop`

### 4.3 刷りの決まり（ここを外すと刷り物に見えない）

1. **一版目はベタ（`source-over`）、二版目からは掛け合わせ（`multiply`）。**
   全部 multiply にすると十段重ねたときに濁って読めなくなる。ベタで下を隠し、
   同じ具材の中でだけ掛け合わせて色に深さを出す。
2. **一枚ごとに墨の輪郭を引く。** `lineWidth = max(2, 具材の幅 * 0.013)`、`lineJoin:'round'`。
   **これが最重要。** 輪郭が無いと絵が締まらず、黄色い紙の上で黄色いチーズが消える。
3. **垂れは短く、左右非対称に。** チーズの垂れは、チーズ本体と同じ濃さの黄で、
   長さはチーズの高さの 1.2〜1.6倍まで。細く長く垂らすと牙に見える。
   左右で長さを変え、位置も対称にしない。
4. **版ずれ。** 色ごとに固定のずれ量を持つ：red `(+1.5, -1.1)`、yellow `(-1.3, +1.2)`、
   green `(+1.1, +1.4)`、ink `(0,0)`。毎回乱数で決めない（ちらつく）。
5. **粒子。** 起動時に一度だけノイズタイル（90×90、30%の画素にランダムな不透明度）を焼き、
   `createPattern` にする。描画の最後に `destination-out` で `globalAlpha .13` で抜く。
6. **かたちは手描きのゆらぎを持たせる。** 直線・真円は使わない。
   輪郭の各点を `sin` の重ね合わせ（周波数 2, 5, 9 くらい）で揺らす。
   両端は `sin` のイージングで細らせ、カプセル状に閉じる。

### 4.4 積み方

- 高さの取り分：`unit = (H * 0.84) / max(0.84, 全段の h の合計)`。
- **段が増えたら上バンズの取り分を減らす。** `domeK = min(1, 0.95 / max(0.86, 生の合計))` を
  `bunTop` の `h` にだけ掛ける。これが無いと十段のとき帽子だけ巨大になる。
- **幅は段数に連動させる。** `bw = min(W * 0.86, unit * 0.72)`。
  高さだけ縮めると、背が高いほど平べったくなる。
- 重なりは **0.76**（次の段の中心を、前の段の高さの 0.76 ぶんだけ上へ）。
  0.84 だと段のあいだに隙間が空いて、組み上がって見えない。
- **上下の端の段が本体から離れて見えないこと。** 特に下バンズ。
  カプセルの端が細るぶん、隙間は中央より端で広く見える。完成形を目で見て確かめること。
- 積み上げたあと**全体を canvas の中央に寄せる**（上端と下端を測ってオフセット）。

### 4.5 出現アニメーション

`t` に `easeOutBack`（オーバーシュート係数 1.9）を掛け、`(1-e) * -H * 0.6` だけ上から落とす。
不透明度は `min(1, t*2.2)`。`prefers-reduced-motion` のときは跳ねさせない。

## 5. 画面の構成

| # | id / 種別 | 紙の色 | 内容 |
| --- | --- | --- | --- |
| 1 | `#hero` | yellow | 表紙 |
| — | 帯 | ink | 流れる情報の帯 |
| 2 | `#build` | paper | スクロールで組み立て |
| 3 | `#grill` | red | 焼き |
| 4 | メニュー | paper | お品書き |
| — | 帯 | ink | 流れる情報の帯 |
| 5 | `#stack` | green | 自分で積む |
| 6 | 店 | dark | 店の情報とフッター |

### 5.1 表紙

- 左に極太の **「ガブリ」**（`clamp(4.6rem, min(19vw,25vh), 15rem)`）。二行に折り返ってよい。
- 右にバーガーの canvas（完成形、全段 `t=1`）。
- 右上に **傾いた丸い値札**：`¥1,280 / TAX IN`、赤地・白文字、墨の輪郭 4px、`rotate(-11deg)`。
- **バーガーを押すと齧れる。**
  - 欠けは `destination-out` の円を4つ重ねて不揃いに抜く。左右交互、下へずらしながら最大3回。
  - **欠けた断面にも墨の縁を残すこと。** 抜いたあとに同じ形を細い墨線でなぞる。
    輪郭の強い絵柄の中で、そこだけ線が途切れていると壊れて見える。
  - 4回目でリセット。
  - 押した瞬間に canvas を `scale(1.04, .93)` に潰して 170ms で戻す。
  - 「ガブリ！」の文字が赤地に墨の縁取りで飛び出して消える（620ms）。
  - **キーボードでも押せること**（`tabIndex=0`、Enter / Space）。
- 「バーガーを押すと、齧れます。」の注記は**墨地に黄文字の札**にする。黄色の上の薄墨は読めない。

### 5.2 スクロールで組み立て（`height:560vh`、狭い画面では 660vh）

- 左に canvas、右に七段の一覧。
- スクロール量を `--p`（0→1）に正規化し、段 `i` の進捗は `clamp01(p * (段数 + 1.1) - i)`。
- 一覧の現在段は `floor(p * (段数+1.1) - .35)` を反転表示（墨地に白文字、6px 右へずらす）。
- 未選択の段は `opacity:.46`。それ以下だと読めない。

### 5.3 焼き

- 中央にパティの側面図。**赤でベタ→墨を重ねる濃度が `p` で 0.18→0.80 に上がる**（生→焼き上がり）。
- 焦げの点は起動時に26個ぶんの位置と出現タイミングを決め打ちしておく（毎フレーム乱数だとちらつく）。
- パティにも墨の輪郭を引く。
- 湯気：黄色の線を5本、`p` に応じて濃くする。`sin` でうねらせる。
- 数値を三つ、`p` に連動させる：鉄板 0→250℃ / 片面 0→90秒 / 中心 8→64℃。

### 5.4 お品書き

太罫（3px）のカードを4枚。1枚目だけ黄色地にして「まずこれ」の札を付ける。

### 5.5 自分で積む（この画面が仕掛けの主役）

- 具材のボタンを押すと**積み上がり、合計金額が変わる**。基本 ¥980 に追加料金を足す。
- 押した具材だけ落下アニメーションを再生する（`requestAnimationFrame`、460ms）。
- 積んだものは札の一覧に出す。空のときは点線の枠で「まだ何ものっていません」。
- **6段で「だいぶ背が高くなってきました。」、9段で「もう口に入りません。潰してください。」、
  12段で打ち止め**（「もう積めません。これ以上は皿です。」）。
- 「ぜんぶのせ」「はじめから」の二つのボタンを置く。

## 7. 技術上の決まりと、踏みやすい穴

1. **スクロール量は JS が測って `--p` に配るだけ。描くのは CSS と Canvas。**
   `scroll` は `requestAnimationFrame` で 1フレーム 1回に束ねる。
2. **固定面の高さは実測する。** `100svh` の sticky を `window.innerHeight`（＝`100vh`）で割ると、
   アドレスバーが出入りするモバイルで進行度が 1 に届かない。
   `travel = section.height - stage.offsetHeight` を使う。
3. **`.stage` の `position:sticky` を後から書いたクラスで潰さないこと。**
   `.stage{position:sticky}` の後に `.foo{position:relative}` を同じ要素に当てると、
   後勝ちで sticky が消える。sticky は既に絶対配置の包含ブロックになる。
4. **`prefers-reduced-motion`** では固定を全部解き、絵は完成形で静止させる。
   動きを止めるだけだと、何も起きない画面を何スクリーンも送らせることになる。
5. **横スクロールを出さない。** `document.documentElement.scrollWidth - clientWidth === 0` を保つ。
6. `body` に必ずトークン由来の `background` を置く（透明だと外側の地色を拾う）。
7. キーボードの `:focus-visible` に見える状態を与える。
8. リサイズと `document.fonts.ready` で測り直す。
