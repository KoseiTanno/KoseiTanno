# 実装仕様書：ホテル凪

尾道の丘に建つ架空のホテルのサイトを一枚の HTML で作る。
この文書は Opus 5 が書いた仕様であり、実装者はこの通りに作ること。

---

## 0. 成果物の形式

- **1ファイル。ビルドもライブラリも使わない。** 素の HTML / CSS / JS。
- Artifact に載せるため、`<!doctype>` `<html>` `<head>` `<body>` は**書かない**。
  ファイルは次の順で始める：`<title>` → `<link rel="preconnect">`×2 → Google Fonts の `<link>` → `<style>` → マークアップ → `<script>`。
- 外部アセット禁止。**Google Fonts だけは許可**。絵はすべて **Canvas 2D**。
- JS の先頭で `document.documentElement.lang = 'ja'` を立てる。

---

## 1. 何を作るか

尾道の丘に建つ架空のホテル **「凪」**（HOTEL NAGI）。全14室。
名前の由来は瀬戸内の **夕凪** — 陸から吹く風と海から吹く風が入れ替わり、
そのあいだ風がぴたりと止まる三十分のこと。

**ホテルのサイトは読ませるだけでは終わらない。泊まる日を選ばせるところまでが仕事。**
だから後半に**実際に動く予約UI**を置く。前半の演出と同じだけ手をかけること。
よくあるホテルサイトが外部ウィジェットに丸投げしている部分を、ここでは自前で作る。

**前半の主題は「光と時刻」。スクロールが一日の経過になる。**

## 4. Canvas の部屋描画（`drawRoom(canvas, hour, opt)`）

**関数は一本。前半の大きな画面も、客室カードの小さな絵も、これ一本で描く。**
`opt` で窓の寸法だけ差し替えられるようにする。

### 4.1 寸法（canvas の W, H に対する比）

- 床の見切り `FY = 0.66H`
- 窓 `x: 0.21W – 0.79W`、`y: 0.16H – 0.53H`（`opt.wx0/wx1/wy0/wy1` で上書き可）
- 水平線 `seaY = wy0 + 窓の高さ * 0.52`

### 4.2 描く順と中身

1. **壁**をベタ塗り。窓の中心から放射状に `rgba(255,255,255,.10)` → 透明の照り返しを重ねる。
2. **床**を塗り、見切りに `rgba(0,0,0,.22)` の細い線（幅木）。
3. **空**：窓の中を `skyT`（上）→ `skyB`（下）の縦グラデーション。
4. **対岸の島**：水平線より上に出る稜線。`sea` 色で塗り、その上に `rgba(0,0,0,.34)` を重ねる。
   頂点は4つ、高さは窓の高さの 3.5%〜10.5% でばらつかせる。
5. **海面**：`sea` でベタ。上端に `rgba(255,255,255,.10)`、下端に `rgba(0,0,0,.22)` の縦グラデ。
6. **日の道**（太陽の真下だけ光る水面）：
   - まず柱状のグラデーション（`sun` → 透明）を、水平線で細く・手前で広がる台形に置く。
   - その上に不揃いな横縞を22本。**手前ほど間隔があく**（`f*f` で配置）、幅も手前ほど広い。
   - どちらも `globalCompositeOperation:'lighter'`。等間隔・等幅にすると梯子に見える。
7. **水平線**の線（`rgba(255,255,255,.22)`、1px）。
8. **夜の対岸の灯り**：`lamp > .2` のとき、水平線のすぐ上に小さな暖色の点を26個。
9. **太陽**：
   - `t = (hour - 5.0) / (19.1 - 5.0)`、`0 < t < 1` のとき出す。高度は `sin(πt)`。
   - **位置は `sy = seaY - sin(πt) * (seaY - wy0) * 0.86`。**
     つまり **水平線から昇り、水平線へ沈む**。窓の下端を基準にすると海に潜って見える。
   - 太陽の周りに放射グラデーションのにじみ。
10. **床に落ちる光の帯**（`sin(πt) > 0.04` のとき）：
    - 長さ `len = (H - FY) * (0.30 + 2.1 * (1 - 高度))`。**日が低いほど長く伸びる。**
    - 横ずれ `shear = (0.5 - t) * W * 1.15`。**太陽と反対側へ流れる。**
    - 窓の横幅から始まる四辺形。`lighter` 合成。
    - **窓ぎわが濃く、手前ほど薄くなる**線形グラデーションを掛ける。均一だと硬い。
    - 濃度 `a = clamp01(高度 * 1.6) * 0.62`、帯は `a * 0.42`、芯は `a * 0.34`。
11. **窓の桟の影**：縦桟2本ぶんを、光の帯と同じ向きに `floor` 色で横切らせる。
12. **窓の桟**：縦2本（1/3, 2/3）、横1本（水平線の位置）。壁の色で塗る。外周に細い暗線。
13. **ベンチ**：`x: 0.34W – 0.62W`、天板の上端は `FY - 0.085H`。脚は2本、床で止める。
    **窓に掛からない位置に置くこと。**
    影は光と同じ向きに、長さ・横ずれとも光の帯の半分。
14. **室内灯**（`lamp > 0.18` のときだけ）：
    右手（`0.80W`）に床置きのランプ。支柱・台座・台形の笠を持たせ、笠の下端を光らせる。
    **点だけを浮かせない。** 床に暖色の放射グラデーションを `lighter` で落とす。
15. **粒子**：ノイズタイルを `overlay` 合成、`globalAlpha .5` で全面に。

## 5. 前半：スクロール＝一日（`#day`、`height:760vh` / 狭い画面 900vh）

- sticky な全画面ステージに canvas を敷き、その上に文字を重ねる。
- 上に暗い→透明→暗いの `veil` を掛けて文字の可読性を確保する。
- 左上にホテル名 `凪 / HOTEL NAGI — ONOMICHI`、右上に**大きな時計**（`HH:MM`）と進行の弧。
- 下に、その時刻の見出しと本文。

### 5.1 六つの時刻

| 時 | 見出し | 本文 |
| --- | --- | --- |
| 5.35 | 夜が明ける | 空より先に、海の色が変わります。この時間に起きられるのは、旅先にいるあいだだけです。 |
| 7.20 | 朝食 | パンは坂の下のパン屋から、7時に届きます。焼きあがりの時間に合わせて配達をお願いしています。 |
| 10.6 | 光が壁を昇る | 床にあった光が離れて、壁を昇りはじめます。掃除はこの時間に。部屋にはどなたも入れません。 |
| 14.2 | テラスが開く | 庇の影ができるのは、この時間からです。日が回りきるまで、ここがいちばん涼しい場所になります。 |
| 18.7 | 夕凪 | 陸から吹く風と、海から吹く風が入れ替わる三十分。そのあいだ、風がぴたりと止まります。この宿の名前は、ここから取りました。 |
| 21.2 | バー | 灯りは絞ってあります。対岸の家々の明かりが、そのぶんよく見えます。24時まで。 |

### 5.2 時刻の進み方（等速にしないこと）

**見出しのある六つの時刻で足を止め、あいだは速く送る。**
スクロール量 `p` から時刻への写像を、次の節点を通る折れ線にする（`n` は見出しの数＝6）：

```
(0, 5.0)
各 i について  ((i + 0.18) / n, HOURS[i].h)  と  ((i + 0.82) / n, HOURS[i].h)
(1, 22.2)
```

現在の見出しは `clamp(floor(p * n), 0, n-1)`。

**等速にすると、時計が 15:40 のときに「14:12 テラスが開く」を読ませることになる。**
時計と本文が食い違うのは、この演出では致命的。

## 6. 後半：実務側（時刻連動しない）

前半の色は時刻の関数だが、**後半は固定**。予約UIの可読性を時刻に預けてはいけない。

**明るいときは 15:00 の光、暗いときは 21:00 の光**で組む。同じ色の体系のまま時刻だけ違う、という扱い。

| トークン | 明 | 暗 |
| --- | --- | --- |
| `--page` | `#E4E4DC` | `#181D23` |
| `--panel` | `#EDEDE7` | `#1F252C` |
| `--text` | `#1A2028` | `#DFE5E4` |
| `--dim` | `#5D646A` | `#98A2A6` |
| `--line` | `#C6C7BC` | `#303A43` |
| `--line-soft` | `#DBDBD2` | `#252D35` |
| `--sun` | `#C2703A` | `#D79A5E` |
| `--range` | `#D2D6CB` | `#2A333C` |

`@media (prefers-color-scheme: dark)` は `:root:not([data-theme="light"])` で包み、
`:root[data-theme="dark"]` でも同じ値を定義すること（三状態すべてに効かせる）。

| --- | --- | --- | --- | --- | --- | --- |
| 朝凪 | ASA-NAGI | ダブル | 26㎡ | ¥22,000 | 5.67 | .24 / .76 / .16 / .58 |
| 凪 | NAGI | ツイン | 32㎡ | ¥28,000 | 14.0 | .14 / .86 / .13 / .60 |
| 夕凪 | YU-NAGI | スイート | 48㎡ | ¥46,000 | 18.7 | .10 / .90 / .11 / .62 |

本文：

### 6.2 予約UI

- 月のカレンダー。今月から10か月先まで。前月・翌月ボタン（範囲外は `disabled`）。
- 各セルに**日付と、その日の料金**（`28k` のように千円単位）。
- 料金：部屋の基本料金 × 曜日係数（金 1.25 / 土 1.40 / 日 1.10 / 他 1.00）、500円単位に丸める。
- **満室は日付から決まること。** 日付文字列のハッシュ `% 13 === 0` を満室とし、`満` と表示して押せなくする。
  **乱数にしてはいけない。読み込むたびに変わったら予約表として嘘になる。**
- 過去の日は押せない。料金も出さない。
- 日付を押すと泊まる日、もう一度押すと出発日。二度目が一度目以前なら泊まる日を置き直す。
- **満室の夜をまたぐ日程は取れない。** その場合は
  `〇月〇日が満室です。この日をまたぐ日程は取れません。` と返し、押した日を新しい泊まる日にする。
- 右側の集計に：部屋名 / 期間 / **一泊ごとの内訳（日付・曜日・金額）** / 泊数 / 合計。
- 部屋タイプを切り替えたら、カレンダーの料金も集計も引き直す。
- 「この日程で問い合わせる」を押すと
  `承りました。……とはいえ、これは架空のホテルです。` と出してボタンを無効化。
- 凡例：`選んだ日` `宿泊する夜` `空室あり` `満 — 満室`。
  **「宿泊する夜」の色は空室と見分けがつくこと**（`--range` を専用に用意したのはそのため）。

- Check in：`15:00 — 22:00 / チェックアウト 11:00`

- Parking：`4台（要予約・無料）`
- Bar：`18:00 — 24:00 / 宿泊されていない方も入れます。灯りは絞ってあります。`
- Breakfast：`7:00 — 10:00 / ¥2,200 / パンは坂の下のパン屋から届きます。`

## 7. 技術上の決まりと、踏みやすい穴

1. **スクロール量は JS が測るだけ。** `scroll` は `requestAnimationFrame` で 1フレーム 1回に束ねる。
2. **固定面の高さは実測する。** `100svh` の sticky を `window.innerHeight`（＝`100vh`）で割ると、
   アドレスバーが出入りするモバイルで進行度が 1 に届かない。
   `travel = section.height - stage.offsetHeight` を使う。
3. **`prefers-reduced-motion`** では固定を解き、canvas を通常の高さのブロックにして
   夕凪の時刻で静止させ、六つの本文をすべて並べる。
4. **狭い画面で「SCROLL」の案内が本文に重ならないこと。**
5. **横スクロールを出さない。**
6. `body` に必ずトークン由来の `background` を置く。
7. 色の定義を `@media` や `[data-theme]` の**中だけ**に書かない。
8. `:focus-visible` に見える状態を与える。カレンダーのセルは `<button>` にして
   `aria-label` に「〇月〇日 ¥28,000」または「〇月〇日 満室」を入れる。
9. リサイズと `document.fonts.ready` で測り直す。

## 8. 完成の条件

- desktop / dark / mobile(390px) / reduced-motion の4条件で描画し、横スクロールと JS エラーが無い。
- **時計の表示と、出ている見出しの時刻が一致している**（等速にしていないことの確認）。
- 太陽が水平線から昇り、水平線へ沈む。海に潜らない。
- 日付を二つ押すと、泊数・内訳・合計が正しく出る
  （例：木・金・土の3泊をツインで取ると 28,000 + 35,000 + 39,000 = ¥102,000）。
- 満室の日は、再読み込みしても同じ日が満室のまま。
