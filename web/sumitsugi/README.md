# 墨継 SUMITSUGI — スクロリテリングのデモ

架空の万年筆をお題にした、スクロール連動（scrollytelling）演出の実装デモです。
`index.html` 1ファイルで完結し、ビルドもライブラリも使っていません。

公開版: https://claude.ai/code/artifact/a3f695ce-e517-4129-9612-53d7e9220623

## 実装している演出

| # | シーン | 手法 |
| --- | --- | --- |
| 1 | 見出し | 静止。ここだけ動かさず、以降の落差をつくる |
| 2 | 落下 | 3行を `--p` の別区間に割り当て、順に沈みながら出す |
| 3 | ペン先 | `--p` で回転・拡大しつつ、注記を時間差で出す |
| 4 | インクの道 | 断面図を `position:sticky` で固定し、本文だけを送る。段の切り替えは IntersectionObserver |
| 5 | 一筆 | `stroke-dashoffset` で線を引き、`getPointAtLength()` でペン先を線の先端に置く |
| 6 | 分解 | 4部品を割付のまま左右に開く爆発図 |
| 7 | 十一日 | 縦スクロールを `translateX` の横送りに変換した工程表 |

## 設計方針

- **JS は測るだけ。描くのは CSS。** スクロール量を `--p`（0→1）に正規化してセクションに書き、
  見た目はすべて CSS 側が `var(--p)` を読んで決める。`scroll` は rAF で 1 フレーム 1 回に束ねる。
- **固定面の高さは実測。** `100svh` の sticky を `window.innerHeight`（＝`100vh`）で割ると、
  アドレスバーが出入りするモバイルで `--p` が 1 に届かない。sticky 要素自身の高さを使う。
- **後半は一度きりの出現に落とす。** 再スクロールで再生し直す演出は酔うため、
  `.reveal` は IntersectionObserver で一度出したら監視を外す。
- **`prefers-reduced-motion` では固定を全部解く。** 動きを止めるだけだと、
  何も起きない画面を何スクリーンも送らせることになるので、ふつうの縦組みの読み物に組み替える。
- ライト/ダークはトークンだけを差し替え、`data-theme` と `prefers-color-scheme` の両方に対応。
