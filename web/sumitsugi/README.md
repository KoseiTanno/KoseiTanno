# 墨継 SUMITSUGI — スクロリテリングのデモ

架空の万年筆をお題にした、スクロール連動（scrollytelling）演出の実装デモです。
`index.html` 1ファイルで完結し、ビルドもライブラリも使っていません。

公開版: https://claude.ai/code/artifact/a3f695ce-e517-4129-9612-53d7e9220623

## 日本語の組み方

- **日本語のフォントを明示的に読み込む。** Google Fonts の Zen Old Mincho（明朝）と
  Zen Kaku Gothic New（ゴシック）。フォールバックにも中国語フォントを混ぜない。
  `Songti SC` のような簡体字フォントが並んでいると、そちらの字形で表示されてしまう。
- **`lang="ja"` を必ず立てる。** 言語指定が無いと、ブラウザは同じ符号位置の漢字を
  中国語の字形で描くことがある。JS の先頭で `documentElement.lang = 'ja'` を設定している。
- **本文の一部を縦組みにする。** `writing-mode: vertical-rl` + `text-orientation: mixed`。
  縦組みでは `<br>` ではなく **block 要素が「段」になる**。`inline-block` を並べると段が重なる。

## 絵は Canvas で描く

線画を SVG で持たせると、輪郭が均一すぎて紙と墨の質感が出ない。表現の中心は Canvas に置いた。

| # | シーン | 手法 |
| --- | --- | --- |
| 1 | 見出し | 落ちる縦画を Canvas で。読み込み時に一度だけ引く |
| 2 | 落下 | 墨のにじみ。芯は歪んだ輪郭、外側は放射グラデーションで逃がす |
| 3 | ペン先 | `--p` で回転・拡大しつつ、注記を時間差で出す |
| 4 | インクの道 | 断面図を `sticky` で固定し、本文だけを送る（IntersectionObserver） |
| 5 | 一筆 | 万年筆の線を Canvas で。太らず痩せず、かすれない |
| 6 | 分解 | 四部品を割付のまま左右に開く |
| 7 | 十一日 | 縦スクロールを `translateX` の横送りに変えた工程表 |

**筆と万年筆は別物として描き分けている。** 筆は入り・送り・抜きで幅が変わり、抜きぎわで
かすれる。万年筆の線は幅が変わらず、途切れない — それがこの製品の主張そのものなので、
`penWidth()` と `brushWidth()` を分け、かすれは筆のときだけ入れている。

紙の地は、中間グレーのノイズと繊維の線を一度だけ焼いて `mix-blend-mode: overlay` で敷く。
中間グレーを基準にすることで、明暗どちらの地色でも同じテクスチャが使える。

## そのほかの設計方針

- **JS は測るだけ。描くのは CSS と Canvas。** スクロール量を `--p`（0→1）に正規化して
  セクションに書き、見た目は CSS が `var(--p)` を読んで決める。`scroll` は rAF で束ねる。
- **固定面の高さは実測。** `100svh` の sticky を `window.innerHeight`（＝`100vh`）で割ると、
  アドレスバーが出入りするモバイルで `--p` が 1 に届かない。
- **`prefers-reduced-motion` では固定を全部解く。** 動きを止めるだけだと、何も起きない画面を
  何スクリーンも送らせることになるので、ふつうの縦組みの読み物に組み替える。
- ライト/ダークはトークンだけを差し替え、`data-theme` と `prefers-color-scheme` の両方に対応。
  墨の色は Canvas 側も切り替えを検知して引き直す。
