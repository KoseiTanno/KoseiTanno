# ホテル凪 — スクロールが一日になるサイト

尾道の丘に建つ架空のホテルのサイト。同じスクロール連動の骨組みで作った三つ目
（`../sumitsugi/` は墨と和紙、`../gaburi/` はリソグラフのポスター）。

公開版: https://claude.ai/code/artifact/2233f169-04ba-4d99-b574-7d0f27d28a1f

## 前の二つと何を変えたか

ホテルのサイトは**読ませる**だけでは終わらない。泊まる日を選ばせるところまでが仕事です。
そこで後半に**実際に動く予約UI**を置き、前半の演出と同じだけの手間をかけています。

## 前半：スクロール＝一日の経過

- 5時から22時までの光を、**11段の色見本として手で置き**、あいだを補間しています（`STOPS`）。
  ページの背景・文字・壁・床・空・海・太陽の色すべてが時刻の関数です。
- 窓の外は Canvas。空のグラデーション、水平線、対岸の島、**日の道**（太陽の真下だけ光る水面）、
  太陽は**水平線から昇って水平線へ沈み**ます。
- 床には**窓から入った光の帯**が落ちます。日が低いほど長く伸び、太陽と反対側へ流れ、
  窓の桟の影が横切ります。ベンチの影も同じ方向に伸びます。
- 夜は室内灯が点き、対岸の家々に明かりが灯ります。

**時刻の進み方は等速ではありません。** 見出しのある六つの時刻で足を止め、あいだは速く送る
（`hourAt()` の `KNOTS`）。等速にすると「14:12 テラスが開く」を 15:40 に読ませることになり、
時計と本文が食い違います。

## 後半：予約UI

- 日付を二回押すと期間が決まり、**泊数・一泊ごとの内訳・合計**が出ます。
- 金曜 1.25倍、土曜 1.40倍、日曜 1.10倍。部屋タイプを変えると全部引き直します。
- **満室は日付から決まります**（`hash(date) % 13`）。読み込むたびに変わると予約表として嘘になる。
- 満室の夜をまたぐ日程は取れず、どの日が塞がっているかを文で返します。

## 客室カードも同じ描画関数

三つの部屋のカードは、`drawRoom()` に**その部屋の光がいちばんいい時刻**を渡しているだけです。
朝凪は 05:40、凪は 14:00、夕凪は 18:42。窓の寸法だけ部屋ごとに変えています。

## 色とテーマ

明るいときは **15:00 の光**、暗いときは **21:00 の光**で実務側を組んでいます。
同じ色の体系のまま、時刻だけを変えたもの。時刻連動するのは前半だけで、
後半は固定です（予約UIの可読性を時刻に預けるべきではない）。

書体は **Murecho**（200）を見出しに、本文に Zen Kaku Gothic New、
時刻・料金・室番号に **Barlow Condensed**。

## 注記

架空のホテルです。名称・住所・料金・空室状況はすべて創作で、実在の施設とは関係ありません。
